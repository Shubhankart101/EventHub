**Highlights:** Django ORM · Django REST Framework · Swagger/OpenAPI · transaction-safe seat reservations · GitHub Actions · Terraform · Azure App Service · Gunicorn

- Browse and filter events by status or venue.
- Reserve seats with availability validation and database row locking.
- Cancel reservations and restore seats atomically.
- Test every endpoint through Swagger UI and documented JSON examples.
- Validate, deploy, and track the project through GitHub Actions.
